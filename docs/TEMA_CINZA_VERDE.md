# Tema escuro — cinza e verde

Ajuste visual solicitado a partir da prévia de cinza mais claro com verde escuro. A imagem é conceitual: a atualização muda a paleta dos componentes existentes, sem reproduzir um novo layout.

## Paleta

| Papel | Cor |
|---|---|
| Fundo | `#454B48` |
| Cartões | `#5A625D` |
| Campos | `#404843` |
| Cabeçalho | `#505853` |
| Botões principais | `#165B36` |
| Texto principal | `#FFFFFF` |
| Texto secundário | `#E4E9E5` |
| Ações textuais e foco | `#D2F7DE` |

Ações textuais usam verde claro para manter legibilidade sobre cinza. Botões principais usam verde escuro com texto branco; campos, diálogos, menus e estados de seleção seguem os papéis centrais do Material. O tema claro e a escolha Claro/Escuro/Automático permanecem.

## Aplicação

Atualize o código e recompile o aplicativo para Android ou Windows. Não exige migração Supabase. Nenhum APK ou EXE foi gerado nesta atualização.

## Validação

Arquivo Dart formatado. Contraste calculado: texto principal/cartão 6,29:1; texto secundário/cartão 5,12:1; texto branco/botão verde 8,13:1. Não houve execução do aplicativo ou dos testes Flutter neste ambiente.
